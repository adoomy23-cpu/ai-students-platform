# إصلاح الروابط والصور وReact Hooks

الفرع: `fix/phase1-eslint-hooks-images`.
المصدر: `development/phase-1-platform-design` عند `457cb2f`؛ فرع

## التغييرات

- استبدال الروابط الداخلية بـ`Link`، مع الحفاظ على روابط المواقع الخارجية والمرساة.
- استخدام `ContentImage` المبني على `next/image` بدل عناصر `img`، بأبعاد ومقاسات
  استجابة واضحة. الصور الخارجية التي يديرها المعلم تُحمّل من المتصفح باستخدام
  `unoptimized` دون إضافة وكيل صور خادمي مفتوح أو افتراض قائمة نطاقات في القاعدة.
  الصور المحلية تستفيد من محسّن Next.js.
- تثبيت دوال القراءة المشتركة بـ`useCallback` وربط Effects بتبعياتها الفعلية.
- إبقاء حالة التحميل الأولية، وبدء تحميل التحديث من أحداث المستخدم بدل تحديث
  الحالة متزامنًا داخل Effect. تحديث النتائج يتم بعد انتظار الاستجابة.
- حساب اختيار الفصل من البيانات بدل Effect لتحديث حالة مشتقة، مع الاحتفاظ
  بالاختيار الصالح والتحديث الوظيفي للصف الافتراضي.
- إزالة طلب تحميل المحتوى المكرر، ومعالجة تنقل صفحات التفاصيل وفق معرف المورد
  ومنع استخدام استجابة طلب سابق بعد تغيير المعرف أو مغادرة الصفحة.
- تحديث النسخ الاحتياطية أيضًا دون استثنائها من ESLint، وتصحيح مسار استيراد
  Supabase في النسخة الاحتياطية الموجودة بجذر المشروع.

لم تتغير CSS أو الهوية العربية RTL أو تعريفات الجداول والدوال. لم تُعطّل أي قاعدة
ESLint ولم تُضف تعليمات تجاهل. لم تُنفّذ طلبات كتابة أو تغييرات في Supabase.

## نتائج الفحوص وحدودها

- نجحت اختبارات البيانات الستة بتشغيل `node tests/published-quizzes.test.mjs` مباشرة.
- نجح تحليل بناء الجملة لـ٣١ ملف JavaScript/JSX باستخدام Acorn مع JSX، وفحص الفرق.
- فحص التكوين يؤكد بقاء `eslint.config.mjs` دون تغيير، وعدم إضافة تعطيل لقواعد الفحص.
- تعذر التحقق النهائي عبر ESLint وبناء Next.js لعدم توفر المكتبات. محاولات
  التثبيت أُوقفت بطلب المستخدم، ولم تُعد المحاولة بعد ذلك. الطلب السابق للشبكة
  انتهى بالإلغاء، ومحاولة التثبيت السابقة أظهرت `EPERM` لاتصال وكيل الشبكة.

فحص بناء الجملة ليس بديلًا عن ESLint أو البناء أو تشغيل React في المتصفح.
لا يُدّعى تحقق صفر أخطاء وتحذيرات أو تأكيد العدد ١٩/١٢ دون نتيجة ESLint الفعلية.
يلزم قبل الدمج تشغيل `npm run lint` و`npm run build` و`npm test` في Codespaces
أو بيئة تتوفر فيها الاعتماديات، والتحقق بصريًا من الصور وصفحات التفاصيل.
