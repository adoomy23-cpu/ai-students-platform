# توحيد واجهة منصة مدارس الفكر التربوي

الفرع: `design/alfikr-platform-unified`.
الأساس المعتمد على GitHub: `design/alfikr-school-identity` عند `356dacfc6b8b29d50c7a37fb78b0281f55377922`.
كانت ملفات العمل نظيفة قبل إنشاء الفرع؛ لم تُستبدل أي تغييرات محلية.

## النطاق المنفذ

حُدّثت جميع الصفحات الفعلية وعددها **15**:

| المسار | التحديث |
|---|---|
| `/` | الترويسة والتذييل المشتركان، إزالة التنقل السفلي، المحافظة على بطاقات الرحلة والروبوت والاختبارات المنشورة؛ مدخل المعلم بحسب الدور |
| `/login` | نموذج دخول المعلم بالهوية المشتركة، تسميات مرتبطة بالحقول، اقتراح تعبئة البريد وكلمة المرور ورسالة خطأ ميسرة |
| `/content` | بطاقات المحتوى والفيديوهات والشارات وروابط فتح المحتوى وحالات التحميل والفراغ والخطأ |
| `/challenges` | بطاقات التحديات والشارات والأيقونات وزر المشاركة |
| `/challenges/[id]` | تعليمات التحدي وحقول اختيار الطالب ورفع الملفات والمشاركة ورسائل الحالة |
| `/q` | الاختبار التجريبي وأسئلته وأزراره ونتيجته |
| `/quiz/[id]` | اختيار الطالب والأسئلة والإجابات ونتيجة الاختبار والتنبيهات المخصصة |
| `/admin` | بطاقات أقسام الإدارة؛ وصل الأقسام الموجودة للطلاب والفصول والاختبارات والتحديات، توضيح الأقسام المستقبلية؛ إزالة أرقام إحصائية ثابتة مضللة |
| `/admin/students` | النماذج والبحث والفلاتر وبطاقات الطلاب وشارات النشاط؛ نافذة مخصصة لتعديل الاسم |
| `/admin/classrooms` | إنشاء الفصول وبطاقاتها وحالاتها؛ نافذة مخصصة لتعديل الاسم |
| `/admin/content` | نماذج المحتوى وبطاقاته وأزراره؛ تأكيد الحذف بنافذة مخصصة |
| `/admin/quizzes` | النماذج والبطاقات وحالة النشر؛ تأكيد الحذف بنافذة مخصصة |
| `/admin/quizzes/[id]` | معاينة الأسئلة الحالية وأزرار اختيار الإجابات وحالات التحميل والخطأ |
| `/admin/challenges` | قائمة التحديات المنشورة الحالية بالهوية الموحدة |
| `/admin/results` | الإحصاءات والفلاتر وجدول النتائج؛ عرض خلاياه كبطاقات معنونة على الجوال |

لا توجد صفحة فعلية متروكة دون تحديث. احتُفظ بالملفات الاحتياطية القديمة؛ ليست مسارات App Router ولم تُحوّل إلى صفحات جديدة.

## النظام المشترك والتنقل

- `PlatformShell`: الترويسة والشعار والتذييل والرجوع وتنقل الإدارة.
- `PlatformUI`: الأزرار وروابط الأزرار والحقول والقوائم والنصوص الطويلة والبطاقات والشارات والرسائل وحالات الفراغ والتحميل والجداول.
- `DialogProvider`: تنبيه وتأكيد وتعديل نص عبر `<dialog>` داخل المنصة؛ إلغاء عبر Escape أو خارج النافذة؛ إلغاء الطلب المعلق عند تغيير المسار.
- القائمة العلوية على الجوال تشمل جميع الوجهات المتاحة للدور، بلا وجهات مكررة، وتغلق بالاختيار أو الضغط خارجها أو Escape. لا يوجد شريط سفلي ثابت.
- روابط التذييل المكررة أزيلت، مع إبقاء المحتوى والبطاقات التفاعلية. الترويسة غير ثابتة فوق المحتوى.
- الزائر يرى الأقسام العامة ودخول المعلم؛ الحساب المسجل غير المؤكد كمدير يرى الأقسام العامة؛ روابط الإدارة تظهر فقط عندما يعيد `is_admin` القيمة `true` دون خطأ للحساب الحالي. لا تستخدم نتيجة قديمة بعد تغيير الجلسة.
- فحص الدور مخصص **لظهور التنقل فقط**، وليس بديلًا عن صلاحيات Supabase. لم تُغيّر حماية المسارات أو تسجيل الدخول أو اعتماد الطلاب. استُخدم عقد `is_admin` المنطقي الموجود أصلًا في صفحة الدخول؛ لم يُفترض عقد جديد لدوال ملفات الطلاب.
- الألوان والخطوط محلية ومشتركة، والأيقونات من أشكال Lucide الرسمية المرخصة؛ لا توجد مكتبات إضافية أو خط خارجي مطلوب.
- اسم المدرسة النصي أصبح «مدارس الفكر التربوي». لم تتغير صورة الشعار الأصلية ولا ألوانها ولا تناسبها.

## حدود الوظائف الموجودة

لا توجد مسارات تسجيل الطالب أو استكمال الملف أو انتظار الاعتماد أو إدارة طلبات الاعتماد في هذا الأساس. لا توجد صفحات مستقلة للوحة الشرف أو مراجعة الأعمال أو إعدادات الهوية أو الإحصاءات التفصيلية؛ لوحة الشرف الحالية قسم «قريبًا» في الرئيسية. بقيت روابطه إلى القسم الفعلي الموجود.

`/admin/challenges` قائمة منشورة وليست محرر تحديات، و`/admin/quizzes/[id]` يعرض الأسئلة الحالية وليس محررًا مكتملًا؛ زر الإنهاء هناك كان دون معالج وظيفي أصلًا. وثّقنا هذه الحدود دون اختراع وظائف أو تغيير عقود البيانات. اختيار اسم الطالب اليدوي في الاختبارات والمشاركات بقي كما هو، وفق شرط الحفاظ على آلية الحساب الحالية.

## التحقق الفعلي

- `npm test`: **58 اختبارًا ناجحًا** (6 لاختبارات المنشورة، 45 للاستجابات غير المتزامنة وإلغاء الطلبات، 7 للتنقل والوجهات والتحقق من ظهور صلاحيات الإدارة).
- فحص عرض بنيوي منفصل: **30 حالة** للصفحات الـ15 في حالتي التحميل والمحتوى، مع React وNext والبيانات محاكاة. تحقّق من ترويسة وتذييل و`main` واحد، وعدم تكرار معرفات الحقول، وصحة ارتباط التسميات وخلايا النتائج. هذا ليس اختبار متصفح أو اختبار Supabase.
- فحص Acorn مع JSX: **39 وحدة مصدر** سليمة نحويًا ومراجعة استعمال الاستيرادات. هذا ليس ESLint.
- مقارنة شجرات استدعاءات المصدر: **98 استدعاء Supabase موجودًا بقي مطابقًا**؛ لا توجد نوافذ `alert` أو `confirm` أو `prompt` أصلية في الصفحات الفعلية.
- `git diff --check`: ناجح.
- SHA-256 للشعار، دون تغيير: `b8669a45059324cecf0340b40514f14a69e695a67e9b5f1ce1bcbae9907e2d49`.
- `npm run lint` جُرّب وتعذر: `eslint: not found`.
- `npm run build` جُرّب وتعذر: `next: not found`.
- مكتبات Next.js المحلية وأدلتها المرفقة غير مكتملة في هذه البيئة؛ لم تُحاول إعادة تثبيت المكتبات ولم تُغيّر الإصدارات أو قواعد ESLint.
- محاولة Chromium الفعلية تعطلت بسبب `setsockopt: Operation not permitted`. محاولة صلاحية إضافية أُلغيت؛ لم تُنتج معاينة جوال أو كمبيوتر معتمدة. يلزم فحص المتصفح والبناء وESLint داخل Codespaces قبل اعتماد الواجهة.
- لم يُختبر تسجيل الدخول أو الحفظ ضد قاعدة حية، ولم تُقرأ بيانات طلاب أو تُغيّر قاعدة البيانات أو RLS أو أسرار البيئة.

## المعاينة في Codespaces

من داخل مجلد المستودع، بعد حفظ عملك المحلي، شغّل:

```bash
git fetch origin && git switch design/alfikr-platform-unified && git pull --ff-only origin design/alfikr-platform-unified && npm run lint && npm run build && npm test && npm run dev
```

الأمر لا يجبر استبدال التغييرات المحلية ولا يثبت مكتبات؛ يتوقف عند أي فحص فاشل. راجع المقاسات 320 و390 و768 و1440 بكسل، وفتح القائمة وإغلاقها، والنماذج والنوافذ وخيارات الإجابات وجدول النتائج؛ استخدم بيانات اختبار مخصصة عند تجربة الحفظ. لم يُنفذ نشر أو دمج في `main`.
