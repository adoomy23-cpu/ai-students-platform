# المرحلة الأولى: الهيكل والواجهة الرئيسية

المصدر: `adoomy23-cpu/ai-students-platform`، الإصدار `69c824e`.
الفرع: `development/phase-1-platform-design`.

## النطاق

- واجهة رئيسية عربية RTL بألوان كحلية وزرقاء وبرتقالية وبيضاء.
- مكونات منفصلة للهوية والأيقونات والرسوم وعرض الاختبارات.
- تنسيق `home.css` معزول بأسماء `ph-*` لتجنب تغيير الصفحات القديمة.
- إصلاح روابط الاختبارات من `/q?quiz=...` إلى `/quiz/[id]`.
- عرض حالات التحميل والفراغ وفشل الاتصال وإعادة المحاولة دون نوافذ المتصفح الافتراضية.
- قراءة بيانات الاختبارات العامة فقط؛ لا قراءة لبيانات الطلاب ولا كتابة إلى Supabase.

## التشغيل والتحقق

تتطلب الاعتماديات الحالية Node.js 22 أو أحدث. استخدم متغيرات البيئة الموجودة للمشروع الصحيح:
`NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`.
لا تضع مفاتيح إدارية في المتصفح ولا تحفظ قيم الأسرار في Git.

```sh
npm test
npm ci
npm run lint
npm run build
npm run dev
```

اختبارات البيانات تعمل دون تثبيت مكتبات أو الاتصال بالقاعدة.
البناء الكامل وفحص ESLint يتطلبان تثبيت الاعتماديات.

## حدود هذه المرحلة

الصفحة الرئيسية صفحة عامة وليست لوحة طالب مصادق عليها. صفحات الإدارة القديمة محفوظة؛
نوافذها الافتراضية ستُستبدل عند تطويرها. لا تتضمن هذه المرحلة اعتماد الحسابات أو
حماية RLS أو تخصيص الهوية من لوحة الإدارة. قيمة الهوية الحالية إعداد عرض محلي فقط.
لوحة الشرف موضحة كميزة قادمة دون أسماء أو درجات تجريبية.

قبل العمل على الحسابات، يجب فحص تعريفات RPC والسياسات الموجودة. لا يُفترض شكل
`get_my_student_profile` أو غيرها ولا يُعاد بناء مخطط قاعدة البيانات.

لم تُنفذ ملفات SQL أو عمليات حذف أو نشر. الفرع لا يمثل التغييرات المحلية غير
المرفوعة في Codespaces. نسخة العمل المحلية جُلبت عبر موصل GitHub بسبب تعذر الاستنساخ؛
تُحفظ التغييرات البعيدة فوق شجرة GitHub الأصلية دون استبدال الملفات الأخرى.

## نتيجة التحقق في بيئة العمل

- اجتازت اختبارات البيانات الستة وفحص بناء الجملة للملفات الجديدة و`git diff --check`.
- اجتاز عرض بنيوي دون اتصال حالات التحميل والفراغ والخطأ وعدم توفر الاتصال والنجاح،
  مع التحقق من الروابط والمرساة والنصوص الآمنة، باستخدام بدائل React/Next للاختبار فقط.
- تعذر تثبيت الاعتماديات بسبب الشبكة. لم يكتمل `next build` أو ESLint.
- تعذر تشغيل Chromium بسبب قيود النظام؛ اختبار التصميم بصريًا على الجوال والكمبيوتر
  والتفاعل الفعلي وإعادة المحاولة داخل Next.js ما زال مطلوبًا قبل الدمج أو النشر.
