# الرئيسية المختصرة — مدارس الفكر التربوي

الفرع: `design/alfikr-home-minimal`.
الأساس على GitHub: `73e61b3cc8ce9916080314164d9c27d365dfe0f4` في `design/alfikr-platform-unified`.

## التنفيذ

- الرئيسية تعرض ترحيبًا قصيرًا، الروبوت الحالي، عنوان «فكرة صغيرة. اكتشاف كبير.»، جملة واحدة وزر «ابدأ الاستكشاف».
- ثلاث بطاقات صغيرة قابلة للنقر بالكامل: تعلّم إلى `/content`، تحدَّ إلى `/challenges`، اختبر إلى `/quizzes`.
- أزيل من عرض الرئيسية فقط: قائمة الاختبارات، شريط المبادئ، رابط الفيديو الإضافي، بطاقات الأعمال ولوحة الشرف المستقبلية، ولوحة المعلم الكبيرة. لم تُحذف مكونات العرض أو بياناتها أو وظائف الصفحات الأخرى.
- قائمة الاختبارات المنشورة نُقلت، بموافقة المستخدم، إلى صفحة فعلية `/quizzes` تستخدم `PublishedQuizzes` نفسه دون تعديل استعلاماته أو منطق تحميله أو حالات الخطأ والمحاولة. لا تعرض بيانات وهمية.
- لم يُضف شريط إعلانات؛ لا يوجد مصدر إعلان حقيقي متحقق منه في هذا العمل.
- الترويسة والشعار والقائمة والتذييل المشتركة بقيت كما هي. حُدث رابط الاختبارات ورابط الرجوع إليها، وأزيل رابطا الأعمال ولوحة الشرف إلى أقسام الرئيسية المحذوفة. لا توجد صفحات مستقلة لهذين القسمين في النسخة الحالية؛ مشاركات الطلاب تبقى داخل التحديات، وروابط المعلم تبقى وفق تحقق الصلاحيات الحالي دون تغيير.
- التنسيق الجديد Mobile First ومعزول في CSS Modules؛ لم تتغير أنماط الصفحات الأخرى. بطاقات عمودية مضغوطة للجوال وثلاثة أعمدة بدءًا من 768 بكسل، وحقول الشبكة قابلة للانكماش. أزرار لمس لا تقل عن 46 بكسل وعناوين متوازنة من 23 إلى 40 بكسل.

## الملفات

- `src/app/page.js`: الهيكل المختصر فقط، دون تحميل قائمة الاختبارات في الرئيسية.
- `src/app/landing.module.css`: تنسيق الرئيسية المعزول للجوال والكمبيوتر.
- `src/app/quizzes/page.js` و`quizzes.module.css`: عرض القائمة الحالية في صفحة مستقلة.
- `src/config/platform.mjs`: النصوص والوجهات المختصرة للبطاقات الثلاث.
- `src/config/navigation.mjs`: إزالة روابط الأقسام المحذوفة من الرئيسية وربط الاختبارات بصفحتها الفعلية.
- `tests/navigation.test.mjs`: تحديث الوجهات المتوقعة في اختبارات التنقل.

## نتائج التحقق الفعلية

- `npm test`: نجحت الاختبارات الـ58، بما فيها مراجعة وجود وجهات القائمة وعدم تكرارها وصلاحيات ظهور روابط الإدارة وروابط الرجوع.
- فحص بنيوي مستقل باستخدام React وNext وبيانات محاكاة: 32 حالة عرض للصفحات الـ16 في حالتي التحميل والمحتوى. تحقّق من ترويسة وتذييل وmain واحدة، والروابط والمسارات والمراسي الفعلية، ومن وجود ثلاث بطاقات وروبوت وغياب أقسام الازدحام من الرئيسية. ليس اختبار متصفح أو اختبار قاعدة حية.
- فحص Acorn/JSX: 40 وحدة مصدر سليمة نحويًا مع مراجعة استخدام الاستيرادات؛ ليس بديلًا عن ESLint.
- مقارنة المصدر: الاستدعاءات الـ98 الموجودة لقاعدة Supabase بقيت مطابقة. ملف الشعار لم يتغير، وSHA-256: `b8669a45059324cecf0340b40514f14a69e695a67e9b5f1ce1bcbae9907e2d49`.
- `git diff --check`: ناجح.
- `npm run lint`: جُرّب وتعذر لأن `eslint` غير مثبت في البيئة.
- `npm run build`: جُرّب وتعذر لأن `next` غير مثبت في البيئة.
- TypeScript: المشروع JavaScript، ولا يوجد `tsconfig.json` أو سكربت فحص أنواع أو `tsc` محلي؛ لم يُنفّذ فحص أنواع.
- معاينة Chromium جُرّبت بحد زمني 5 ثوانٍ؛ فشل بدء المتصفح بسبب `sandbox_host_linux.cc: shutdown: Operation not permitted`. لا توجد نتيجة معاينة بصرية معتمدة للجوال أو الكمبيوتر. لم يُطلب تجاوز Sandbox أو تثبيت مكتبات.
- لم تتغير ملفات تنفيذ تسجيل الدخول أو الاختبارات أو التحديات أو لوحة الإدارة، ولم تُقرأ بيانات طلاب ولم تُعدّل Supabase أو RLS أو `main`. لم يُنفّذ نشر.

داخل مجلد المستودع في Codespaces، بعد حفظ العمل المحلي:

