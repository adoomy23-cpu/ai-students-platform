# هوية مدارس الفكر التربوية — الصفحة الرئيسية

الفرع: `design/alfikr-school-identity`، من الإصدار `0d3d94f`.
النطاق المعتمد: نظام الهوية والصفحة الرئيسية فقط، قبل تطبيق التصميم على بقية الصفحات.

## مرجع الهوية

الشعار المرفق محفوظ في `public/alfikr-school-logo.png` دون تغيير بايت واحد أو
إعادة رسم أو قص أو تعديل ألوان. تعرضه الترويسة والتذييل باستخدام Next Image
مع المحافظة على نسبته الأصلية وتقديم الملف الأصلي دون تحويل.

ألوان الشعار المستخرجة: الذهبي `#E5B822`، النحاسي `#AB5E27`، الرمادي `#8A8D91`.
تكملها خلفيات عاجية `#FFFDF7` ونصوص فحمية `#171717` ودرجات دلالية هادئة.

## نظام التصميم

- خط IBM Plex Sans Arabic محلي بأوزان 400 و500 و600 و700؛ لا طلبات إلى Google Fonts.
- أيقونات Lucide الرسمية محليًا بهندسة موحدة، دون Emoji أو إضافة اعتماد npm.
- متغيرات ألوان ومسافات وأنصاف أقطار وظلال خفيفة في `src/styles/alfikr-tokens.css`.
- نطاق CSS هو `.school-home`؛ لا تغيير لهوية بقية المسارات في هذه المرحلة.
- مكونات قابلة لإعادة الاستخدام: SchoolBrand وSchoolIcon وMobileNavigation.
- أزرار بارتفاع 48 بكسل، حالات Hover وFocus وDisabled، ودعم الحركة المخففة.
- الروبوت محفوظ مع تعديل ألوانه لتوافق الهوية؛ الشعار الرسمي وحده يمثل المدرسة.
- تصميم يبدأ من الجوال، وقائمة تُغلق عند اختيار الرابط أو Escape، وتنقل سريع
  أسفل الشاشة مع مساحة آمنة حتى لا يحجب المحتوى.

نسب تباين النص المختارة تتجاوز 4.5:1: زر الذهبي بالنص الفحمي، النص الأساسي،
النص الثانوي، الروابط النحاسية، وشارة النجاح. هذه قياسات ألوان وليست تدقيق WCAG كاملًا.

## الحفاظ على الوظائف

روابط المحتوى والتحديات والاختبارات وأعمال الطلاب ولوحة الشرف ودخول المعلم محفوظة.
عرض الاختبارات ما زال يستخدم القراءة الموجودة دون تغيير الاستعلام أو RPC.
لا بيانات طلاب أو نتائج تجريبية. لوحة الشرف توضح أنها ميزة قادمة كما في النسخة السابقة.
لم تُغيّر صفحات تسجيل الدخول والإدارة أو أي سياسات Supabase أو إعدادات البيئة.

## الفحوص الفعلية

- `npm test`: نجحت الاختبارات الـ51 الموجودة.
- فحص JSX وبناء الجملة وفحص الفرق: نجح.
- عشر حالات عرض بنيوي للرئيسية: حالات الاختبارات الخمس × القائمة مفتوحة/مغلقة؛
  نجحت الروابط والمرساة والنصوص الآمنة والشعار. استخدمت بدائل React/Next، وليس متصفحًا.
- تطابق الشعار مع الملف المرفق وتواقيع ملفات WOFF2: نجح.
- `npm run lint -- --max-warnings=0`: تعذر، `eslint: not found`.
- `npm run build`: تعذر، `next: not found`.
- معاينة Chromium: تعذرت بقيود النظام `shutdown: Operation not permitted`.

لم تُحاول إعادة تثبيت المكتبات. مقاسات الجوال والكمبيوتر مكتوبة في CSS، لكن
الفحص البصري الحقيقي وhydration وإغلاق القائمة بلوحة المفاتيح يجب إكمالها في
Codespaces قبل اعتماد التصميم أو النشر. لا يُدّعى نجاح ESLint أو البناء.

## تراخيص الأصول

ملفات الخط الأصلية من IBM/plex وفق OFL، والأيقونات من lucide-icons/lucide وفق ISC؛
نصوص التراخيص محفوظة في `public/licenses/`. شعار المدرسة أصل مرفق من مالك المشروع.

## المعاينة في Codespaces

```sh
git fetch origin design/alfikr-school-identity && git switch design/alfikr-school-identity && git pull --ff-only origin design/alfikr-school-identity
npm run lint -- --max-warnings=0
npm run build
npm test
npm run dev
```

راجع الرئيسية عند 320 و360 و390 و768 و1440 بكسل، وتحقق من تحميل الخط والشعار
والقائمة والتنقل السريع وحالات تحميل الاختبارات. لا يلزم دمج main أو نشر الموقع.
